# Family Feud AI

An AI-powered Family Feud web application that uses **real crowd-sourced survey data** and **AI-generated boards**, with **Gemini-powered semantic guess matching** that understands synonyms, shorthand, and natural language.

## Live Demo

**[Play the game](https://family-feud-ai.onrender.com)**

> Note: First load may take ~30s due to Render free tier cold starts.

---

## Key Features

| Feature | Description |
|---------|-------------|
| **Real Survey Data** | 25 hand-curated boards from real crowd responses and public opinion trends |
| **AI Board Generation** | Gemini generates new boards from trending topics when real boards are exhausted |
| **4-Layer Matching** | Smart matching pipeline: exact, containment, fuzzy, LLM semantic |
| **Semantic Understanding** | "phone" matches "check their phone", "grab food" matches "eat food" |
| **Dynamic Categories** | 8 categories: Career, Daily Life, Entertainment, Food, Relationships, Student Life, Technology, Travel |
| **AI Commentary** | End-of-round commentary generated by Gemini |

## AI / LLM Usage

This project uses the **Google Gemini API** (`gemini-2.0-flash`) in three meaningful ways:

### 1. Semantic Guess Matching (Core Differentiator)
When a player's guess doesn't match via exact, containment, or fuzzy string matching, Gemini acts as a final adjudicator -- understanding that "hang out at the gate" means the same as "stand by the gate early." The prompt is carefully tuned to be **strict enough** to reject false positives (different actions in the same context) while **generous enough** to accept legitimate synonyms and paraphrases.

### 2. Dynamic Board Generation
When real boards are exhausted, Gemini generates new Family Feud boards seeded by trending topics. Boards are validated for structure, cached to disk, and tagged with `source_type: "ai"` or `"hybrid"`.

### 3. End-of-Round Commentary
After each round, Gemini generates a short comment about the results.

## Architecture

```
app/
  main.py              - FastAPI app, lifespan, static mount
  config.py            - Pydantic-settings (env vars, thresholds)
  models/
    schemas.py         - All request/response Pydantic models
  routes/
    pages.py           - HTML page routes (Jinja2)
    api.py             - JSON API endpoints
  services/
    board_service.py   - Board selection cascade + AI fallback
    game_service.py    - Round lifecycle (in-memory state)
    matching_service.py - 4-layer matching pipeline
    ai_service.py      - Gemini integration (ONLY LLM touchpoint)
    cache_service.py   - AI board caching to disk
  static/
    css/styles.css     - Full design system
    js/game.js         - SPA-like game controller
    images/            - Logo and assets
  templates/
    base.html          - Shared layout
    index.html         - Landing page
    game.html          - Game page
data/
  real_boards.json     - 25 curated survey boards
  trending_topics.json - 20 trending topics for AI generation
```

### Matching Pipeline

```
Player guess -> Normalize -> Exact Match -> Containment -> Fuzzy (rapidfuzz) -> LLM Semantic (Gemini)
                  |              |             |               |                    |
              lowercase     "study" =       "phone" in      typos,           "hang out" =
              strip punct   "study"        "check phone"   reorders         "stand by gate"
```

## Local Development

### Prerequisites
- Python 3.11+
- A Google Gemini API key (https://aistudio.google.com/app/apikey)

### Setup

```bash
git clone https://github.com/leojia8/AXLProject.git
cd AXLProject

python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

pip install -r requirements.txt

cp .env.example .env
# Edit .env and add your GEMINI_API_KEY

echo "[]" > data/generated_boards_cache.json

uvicorn app.main:app --reload --port 8000
```

Visit http://localhost:8000

### Running Tests

```bash
python -m pytest tests/ -v
```

## Deployment (Render)

1. Push code to GitHub
2. Connect your GitHub repo to Render (https://render.com)
3. Create a new Web Service and select the repo
4. Render will auto-detect `render.yaml` and configure the build/start commands
5. Add environment variable: `GEMINI_API_KEY` = your key
6. Deploy

## Design Decisions

- **Hybrid data strategy**: Real boards provide authenticity; AI boards provide unlimited variety
- **4-layer matching**: Minimizes LLM calls (80%+ of guesses handled by deterministic layers)
- **Strict semantic prompt**: Tuned to reject false positives (different actions in same context) while accepting legitimate synonyms
- **In-memory state**: Simplicity over DB complexity for ephemeral game rounds
- **Graceful degradation**: App works fully without Gemini API key (just no semantic matching or AI boards)
